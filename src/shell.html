Pathloom

Offline Mermaid workspace

Write a diagram. Start with flowchart TD, then connect steps: A[Request] --> B{Approved?}. Label a branch with B -->|Yes| C[Done]. Changes render automatically.

Follow a path. Select a step in the diagram or the step list. Next follows one connection; at a decision, choose a labeled branch. Back retraces your path. Arrow keys navigate when the diagram has focus.

Keep or share. Download source creates an editable .mmd file. Export viewer creates a validated, interactive HTML file anyone can open offline. Source saves in this browser when available; download a copy for safekeeping.
